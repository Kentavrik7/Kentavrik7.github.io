# Мастерская Анны

Страница для подбора цвета стен в подвальной мастерской: примерка цвета на трёх настоящих фотографиях, картинки с мебелью и советы.

Адрес: https://kentavrik7.github.io/masterskaya/

Страница статическая. Карты для перекраски лежат рядом с фото в `masterskaya/img/` (`*_aux.png`: зона, высота на стене, покрытие; `*_lum.png`: сглаженная освещённость).
